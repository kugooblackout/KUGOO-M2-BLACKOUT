CUSTOM PROJECT

KUGOO M2

BLACKOUT

Кастомная сборка на базе KUGOO M2. Чёрный стиль, фиолетовый неон, подсветка деки, ключ зажигания и уникальные детали, создающие собственный характер.

Смотреть сборку

Изменения

Подсветка деки

Кастомный стробоскопический эффект, который раскрывает стиль проекта ночью.

Ключ зажигания

Установлен отдельный запуск через ключ. Деталь, которая делает сборку уникальной.

Кастомные тормоза

Доработанная тормозная система для уверенного контроля.

Новый руль и вынос

Установлен удобный и стильный руль вместе с новым выносом для комфортной посадки.
